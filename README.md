# Converter-Pixel-System
Assignment 1: Converter and Pixel System
Developed by Devin Williams
Version 1.0.0

Run the java file to activate
Whenever you want to use a function you have to rerun the file

ASCII -> Decimal is self explainable

The Number base converter requires you to enter the number you want to convert, then what base type that number is in, then what base type you want to convert to. The Types you can choose are Decimal, Binary, Octal, and Hexadecimal

The Image Reader reads images placed in the "Images" folder; 3 images are provided, and any images can be added at any time. Simply type out the name and extension of the image (e.g "gojo.png")

The Image Writer reads a txt file in the same folder the program is located in, and it is assumed that you would be generating an image from one of the images read in the "Images" folder, however if you wished to make your own custom image, you can make a txt file and put the height on the first line and the width on the second line, then add the pixel values on the following lines.
